# Milestone 2 Objective

Milestone 2 is **Literature / Model / Feature Evidence Discovery** for infectious disease forecasting workflows.

It is not direct model training, automatic model replacement, or production prediction. The first stage is evidence discovery and candidate strategy construction using safe local fixtures and mock providers.

## Objective

Given a disease, country, prediction target, and horizon, the system should identify:

- disease task definitions;
- candidate feature groups;
- candidate model families;
- supporting evidence sources;
- data requirements;
- evaluation metrics;
- applicability notes;
- risks and limitations;
- recommended next rolling backtest plan.

## Boundary

All real literature discovery, PDF downloads, external APIs, search engines, or paid sources require a later explicit approval step. Model recommendations must be validated by local backtests before any operational use.
