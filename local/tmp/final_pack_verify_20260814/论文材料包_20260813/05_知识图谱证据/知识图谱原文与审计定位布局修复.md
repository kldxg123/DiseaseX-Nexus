# 知识图谱“英文原文与精确审计定位”布局修复

## 原因

旧页面将多个证据卡并排展示，并让英文原文与审计字段共享窄列。长 excerpt、UUID、SHA-256 与 offset 会把卡片横向撑开或纵向拉长，导致展开内容错位、难以逐条核对。这是前端布局与字段展示问题，不是知识图谱数据断链。

## 修复

1. 证据卡列表固定为单列，避免相邻卡片争抢宽度。
2. 展开区在桌面端改为双栏：左侧只放英文原文，右侧只放精确审计定位；窄屏自动退化为单列。
3. 长 ID、SHA 和 excerpt 允许安全换行，禁止溢出容器。
4. 审计定位明确显示：物理页、印刷页、locator 类型、start/end offset、Evidence ID、document version ID、raw excerpt SHA-256、source PDF SHA-256。
5. 未提供的审计字段显示“未记录”，不伪造值。
