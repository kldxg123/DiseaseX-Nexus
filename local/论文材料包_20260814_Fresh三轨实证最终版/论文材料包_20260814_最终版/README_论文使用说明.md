## 指标解释

- WAPE：加权绝对百分比误差，越低越好。
- 预测吻合度：`max(0, 1-WAPE)×100%`，是展示指标，不是分类准确率。
- 区间覆盖率：真实值落入预测区间的比例；高覆盖率不代表点预测误差低。

## 论文引用边界

- Track A（奥地利军团菌）77.3%：历史回放，不是 fresh held-out。
- Track B（芬兰汉坦病毒）72.0%：重复评估，已重分类为非 fresh。

- 本轮没有新增第四条超过 70% 的 Fresh 链路。Track C 与 Track D 已消费；未注册候选中最接近的是泰国流感（WAPE=34.56%、吻合度=65.44%），未达到门禁，因此没有进入 Fresh 消费或可视化。
